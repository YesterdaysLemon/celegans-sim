# The communal specimen shelf

Preserved animals the deployment ships to every visitor. Each file here is a specimen
JSON exactly as the viewer's **Preserve** button produces it — a recorded walk cycle,
genes, morphology, colours — and `index.json` is the list of filenames the museum page
fetches. To share a specimen: drop its file here, add its name to `index.json`, deploy.
Sharing infrastructure beyond that (uploads, galleries, moderation) is explicitly out of
scope for now; this folder is the place it will grow from.
